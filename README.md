## Featured Project (Currently working)

### [CareCycle](https://github.com/<your-username>/carecycle)
A personal health tracker that keeps your health history in one place (headaches, toothaches, rashes, hair fall, tiredness and more), tells you when to see a doctor and which specialist, and lets you book them. Built as a QA engineering portfolio project: the testing around the app is the main focus.

- **Key feature:** Explainable "which doctor, and when?" suggestions. Severe symptoms get "see a doctor soon", recurring ones point to the right specialist, and a live demo on the landing page runs the same rules with no sign-up.
- **Key feature:** Full test pyramid with requirement-to-test traceability: 80+ pytest unit, API and SQL data-integrity tests, Playwright end-to-end tests built with page objects on desktop and mobile screen sizes, and a 10-thread race test that proves double booking is impossible.
- **Key feature:** AI-assisted QA: an LLM test planner with a reviewer pass and a coverage check in plain code, plus a failure-triage agent that diagnoses Playwright failures without editing code.
- **Built with:** Python, FastAPI, SQLAlchemy, SQLite/PostgreSQL, Playwright + TypeScript, pytest, Claude API, GitHub Actions, gitleaks
